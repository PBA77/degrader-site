Privacy policy

Effective date: 9 October 2026 · Extension version 0.7.2

Degrader — Retro listening room is a Chrome extension developed by PBA77. Its single purpose is to apply user-selected retro effects locally to the audio of one browser tab and play that audio back to you.

Audio processing

When you click Engage this tab, Degrader captures the selected tab's audio and processes it in memory on your device using Web Audio. It does not record audio, save audio files or transmit audio to the developer or any server. It does not capture microphone audio, camera video or screen video.

Processing continues when you close the popup. Click Stop processing, close the captured tab or disable the extension to end capture. Starting processing from another tab switches the captured source.

Tab information

Degrader uses tab identifiers to associate settings with open tabs. After you invoke the extension, it checks the selected tab's URL to determine whether it is a supported HTTP(S) page. The title of the captured tab is kept in memory and shown in the popup to identify the playing source. Degrader does not store a browsing-history log or transmit tab titles, URLs or identifiers.

Settings and retention

Named presets, the selected visual style and any default settings migrated from an older version are saved in chrome.storage.local on your device. Preset names are text you choose; they are not sent to the developer. Local preferences persist across browser restarts and extension updates until overwritten or removed with the extension.

Per-tab sound settings are kept in chrome.storage.session. A tab's settings are removed when it closes. Restarting Chrome, reloading, updating or disabling the extension clears this session storage. Audio buffers and playback state are transient and are released when processing stops.

You can overwrite a named preset by saving a sound with the same name. Removing Degrader from Chrome removes its extension storage. Reinstalling starts with the factory settings.

Permissions

  • activeTab: identify the tab you invoke the extension from, check URL support and display its title locally.
  • tabCapture: obtain that tab's audio after you click Engage this tab.
  • offscreen: keep the local audio engine running when the popup closes.
  • storage: remember presets, appearance and per-tab settings.

No uploads, tracking or data sales

The extension makes no requests to developer-operated servers, includes no advertising or analytics services, and requires no account. The developer does not receive the audio, tab information or settings handled by the extension. No user data is sold, transferred for advertising, used for creditworthiness or used for purposes unrelated to the stated functionality. All processing code is bundled with the extension.

Chrome Web Store Limited Use

Degrader's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Accessed information is used only to provide the extension's single purpose described above.

This website and support

This website is hosted on GitHub Pages and has no analytics scripts, tracking pixels or forms. GitHub may process technical request information, such as IP addresses, under the GitHub Privacy Statement. Visiting this website is separate from using the extension; the extension does not automatically contact it.

If you contact us using the GitHub support tracker, your issue and GitHub profile information are public and handled by GitHub. Share only what is needed to describe the problem. Do not include private information or recordings.

Contact and changes

For privacy questions, contact PBA77 through the support tracker. Future changes to data handling will be reflected in this policy and the store disclosures. The effective date above identifies the current policy.
